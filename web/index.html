Pools and Aliases

A pool is one model served by several accounts or API keys, for example Claude Opus 5.5 from two subscriptions, an API key and Devin. Clients ask for the model and CPA spreads requests across every member; your Routing tiers still decide the order. Clients see the plain model id, never a provider name like “(Devin)”. Pools are saved as CPA's own model aliases.
